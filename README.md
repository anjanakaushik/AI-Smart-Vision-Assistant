1. Project Overview
The AI-Powered Smart Vision Assistant is an assistive technology project designed to help blind and visually impaired people understand their surroundings using Artificial Intelligence.
The system uses computer vision and voice technology to identify objects, describe scenes and provide useful information through audio.

2. Features
	•	Object Detection using YOLOv8.
	•	Voice Assistance in Hindi and English.
	•	AI Scene Description.
	•	Object Position Detection (Left, Centre and Right).
	•	Emergency Assistance Voice Alert.
	•	Image Upload for object detection.
	•	Camera Input for capturing images.

3. Technologies Used

	•	gTTS

4. Project Development
The application is developed using Python and Streamlit.
YOLOv8 is used to detect objects in images. The BLIP model is used to generate scene descriptions. The gTTS library converts text into speech so users can hear the information.
The application provides an interactive interface for image uploading, object detection and voice assistance.

6. How to Run the Project
	1.	Install Python on your computer.
	2.	Install the required Python libraries.
	3.	Open the project folder in Command Prompt.
	4.	Run the following command:

python -m streamlit run app.py
	5.	Open the local URL displayed in Command Prompt.

7. Project Purpose
The main purpose of this project is to develop an AI-based assistive system that helps visually impaired people understand their surroundings more easily through object detection and voice assistance.
This application is designed as a supplementary assistive tool and does not replace a white cane, guide dog or established mobility support.
